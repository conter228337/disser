# Поля исследовательской панели

Панель имеет единицу наблюдения «эмитент × опубликованный документ». Даты являются календарными датами в формате ISO 8601 (`YYYY-MM-DD`), суммы отчетности — в рублях, доли и вероятности — от 0 до 1.

| Поле | Назначение | Источник и временная доступность | Обработка |
|---|---|---|---|
| `inn` | Идентификатор эмитента | e-disclosure / RFSD; доступен до построения панели | строка, ведущие нули сохраняются |
| `ticker`, `company_name` | Идентификация | список компаний в `get_inn.py` | описательные поля |
| `year` | Отчетный год | RFSD / строка документа | целое |
| `annual_report_path` | Локальный файл отчета | `annual_reports_ocr.py` | путь, пустое значение допустимо |
| `annual_report_published_at` | Дата публикации отчета | таблица файлов e-disclosure | используется как `feature_cutoff_date` |
| `audit_report_path`, `explanatory_note_path` | Связанные документы | e-disclosure / bo.nalog.ru | пути к файлам |
| `document_sha256` | Контрольная сумма | `text_features.py` | SHA-256 исходного файла |
| `extraction_source` | Способ извлечения | `text_features.py` | `text`, `pdf`, `zip`, `unknown` |
| `extraction_pages`, `ocr_pages` | Качество извлечения | `text_features.py` | количество страниц |
| `report_word_count` | Размер текстового корпуса | `text_features.py` | число токенов |
| `report_positive_share`, `report_negative_share` | Доля словаря тональности | `text_features.py` | лексиконная доля от числа токенов |
| `report_risk_share`, `report_uncertainty_share` | Язык риска и неопределенности | `text_features.py` | доля от числа токенов |
| `report_sentiment_score` | Баланс позитивных и негативных слов | `text_features.py` | `(positive-negative)/word_count` |
| `total_assets`, `equity`, `revenue`, `net_income`, `current_assets`, `current_liabilities`, `cash` | Финансовые признаки | RFSD (`rfsd.py`) | исходные значения; пропуски не заменяются нулем без оговорки |
| `ROA`, `ROE`, `Debt_to_EBITDA`, `Current_Ratio`, `Cash_to_Assets` | Коэффициенты | `main.py` | рассчитываются из доступной отчетности |
| `rating` | Рейтинг, использованный для описания | e-disclosure | в прогнозной модели заменяется последним рейтингом до cutoff |
| `default_events` | Текстовое описание событий | e-disclosure | только для аудита, не входной признак |
| `default_12m`, `default_24m` | Будущий жесткий дефолт | `temporal_targets.py` | `1/0`; `None` при правом цензурировании |
| `default_12m_observed`, `default_24m_observed` | Полнота горизонта | `temporal_targets.py` | 1 — горизонт завершен |
| `rating_target` | Понижение рейтинга за 12 месяцев | `temporal_targets.py` | `1/0/None` |
| `rating_observed` | Полнота рейтингового горизонта | `temporal_targets.py` | 1 — горизонт завершен |
| `feature_cutoff_date` | Последняя дата допустимых входов | дата публикации | все признаки должны быть доступны не позднее даты |

Поля `default`, `default_bond_n`, `default_dates` и годовой `rating` из исходного сборщика полезны для описательной статистики, но не должны без временной фильтрации использоваться как входы прогноза.

## Словарная разметка

`text_features.py` хранит версию алгоритма `ru-fin-sentiment-lexicon-1.0` и четыре лексикона: позитивный, негативный, риск и неопределенность. Для позитивных совпадений дополнительно считается отрицание в окне трех токенов. В отчете следует отдельно привести размер словарей, долю покрытых токенов и ручную проверку выборки.

## Пропуски и цензурирование

Отсутствие документа, ошибки OCR и нераспознанные рейтинги сохраняются в отдельных полях. Неполный горизонт наблюдения не кодируется как отсутствие дефолта: целевая переменная равна `None`, а индикатор `observed` равен 0.
